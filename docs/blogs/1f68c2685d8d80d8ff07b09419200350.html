The floating-point performance of the theoretical base frequency of 2680 v4 is 537.6 GFLOPS, which is equivalent to the theoretical performance of 13500 or 12800H. I currently only use dual channels because I was not sure if it could be used at the time. If quad channels are used, the bandwidth is similar to that of DDR5 4800MHz dual channels. Personally, I don’t recommend 2699 v4 (774.4 GFLOPS) or 2699A v4 (844.8 GFLOPS), although the floating point performance of these two can reach the level of 13700K or 14600K. Dell T5810

I originally wanted to buy Dell T5820, but after looking around, I found that Dell T5810 is more cost-effective. However, since Dell T5810 is a device from early 2015, when AMD was still selling buildings to save itself, and Nvidia had just released 980Ti, T5810 uses the first generation 14nm CPU, the same as the 5th generation Core (yes, the first generation 14nm with a particularly short life cycle between the 4th and 6th generations). , so there are many designs on the device that are different from the current ones, such as Wi-Fi and Bluetooth are not installed by default, and there is no M.2 interface. If you need the number and type of interfaces, then you can look at T5820, which has more interfaces.

CPU

For CPU, you need to see if the BIOS supports v4, because T5810 can use v3 and v4 processors, but the earliest BIOS does not support v4. Regarding this, you can actually look at the sets sold by the store. If it is v4, it is generally supported.

Memory

T5810 only supports 2400MHz memory, which is not high today, but with four channels, the frequency can be used as 4800MHz dual channel.

Moreover, DDR4 ECC 2400MHz memory is cheaper than ordinary memory, but you should pay attention to one thing: buy 2RX4 or 4RX4, because the two cannot be mixed. For example, I bought two 16GB 2RX4s now, so if I want to expand the capacity in the future, I must also buy 2RX4s.

The large capacity of 2RX4 will have a higher frequency, but T5810 only supports 2400MHz at most. If you use a high frequency, you will waste some money, so if you want to buy large capacity memory, it is more cost-effective to buy 4RX4.

It has 8 slots, even if it is a 16GB single stick, the maximum can be 128GB, which is enough even for dual graphics cards (because the dual graphics cards supported are limited, you will understand what I mean in the next section, the maximum is 48GB video memory, and generally the memory is twice the video memory. It is better). Of course, if you need a large capacity of memory, you can use a 64GB single stick, which can have a total of 512GB.

The memory slots are as follows. The insertion method is to insert the white one first, and then the black one when it is full. This point is not written in the document, I asked the store.

Graphics card power supply cable

The graphics card power supply cable of T5810 is 8Pin to dual 6Pin, but there are too few 6Pin graphics cards now, so you need to buy a single 8Pin to single or dual 8Pin.

Why do you need to convert a single power supply? Because the graphics card interface of the power supply board is not the common one now, but the one on the graphics card. In other words, the power supply line of this thing is the same at both ends:

The left side of the picture below is the built-in one, and the right side is the connector used by the current universal power supply:

Interface

The T5810 motherboard information is as follows:

There are two slots for graphics cards (two with “blue ear” buckles). I inserted the graphics card into the “3” slot in the above picture because the power supply line is relatively short.

Although the slot also says that the maximum is 225W, 350W for a single card is no problem, but it is a bit uncertain for dual cards. Because it used to be a 6-pin connector, it is 225W. The power cord generally depends on whether the connector can withstand it. Generally, a single wire can withstand 1500W, and you can calculate it yourself for 8Pin. I asked the master when I went to the factory to buy the wire. This master used to make computer wires in Xujiahui, Shanghai. I specifically asked if the one-to-two conversion could withstand it, and the master told me a lot of the above.

So although there are two slots, if you want to install two 3090s, a total of 700W, at least dual 8-pin, then you need to convert 1 to 4, leaving aside the 75W provided by PCIe, that is, one 8-pin has to carry 550W, which is very dangerous. Although the T5810 has a maximum power supply of 1300W. However, according to the design, it should be possible to install two 225W, but you have to find a single 8-pin graphics card. The Tesla P100 has a relatively high cost performance, but there are also many Tesla cards with a single 8-pin, but the price is very high. The newer single 8-pin graphics card is the 4070 Super (also need to find a manufacturer to make it), and this card is exactly 220W. However, this card does not support NVLink either. This is just a record for future reference.

I put the M.2 to PCIe adapter in slot 6. I bought a single-disk adapter card. According to the document, it supports splitting, so this slot can buy a two-disk adapter card at most. But I bought a single adapter card for cheap. It’s only 10 yuan on Xianyu, and it’s free shipping. I may still need to use a hard drive to cool it later. The laptop is only 42 degrees, but it’s 50 degrees when it’s hanging here (dual system, I installed Ubuntu for it, but the temperature on Windows is 50, and I don’t use anything).

The network card is placed in slot 4. Although there is only one PCIe 2.0 channel, the bandwidth is 500 MB/s, which is equivalent to 4 Gigabit, which is enough for Internet access.

Wi-Fi and Bluetooth

I wanted to buy the Realtek RTL8852BE at first, because it was only 43, which was very cheap, but after looking around for a long time, I found that there were many problems. After searching for a long time, I found that the AX210 actually had 88, so I just bought it. And it is a transfer type, so you can upgrade the network card yourself later:

If you are using Linux, you can just plug it in and use it, but if you are using Windows, you need to download the driver from Intel’s official website in advance: Intel® Wi-Fi 6E AX210 Latest Drivers & Software. Please note that Wi-Fi and Bluetooth are two drivers, both of which need to be downloaded.

Hard disk

I used an M.2 to PCIe hard disk and a SATA hard disk, both of which are solid state. I originally wanted to install a 10TB mechanical hard drive, but after installing it, it was so strange to use, there were many problems, and it often got stuck, so I gave up and used the built-in pure solid state + DAS.

Installing the system

I haven’t installed a dual system for a long time, and Windows gave me a pit: Windows will not display the hard drive name, only “Disk 0” and “Disk 1”, and my hard drives are all 1TB, and I can’t tell them apart. So I suggest installing Windows first, then unplug the hard drive, then plug in another hard drive, and then install Ubuntu.
