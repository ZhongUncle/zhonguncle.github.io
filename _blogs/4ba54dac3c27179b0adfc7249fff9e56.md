`lstopo` is an excellent tool for generating intuitive, concise system topology diagrams. This article documents small issues I encountered while using it—it is not a comprehensive manual. For detailed options, refer to the official documentation: [lstopo(1) - Linux man page](https://linux.die.net/man/1/lstopo).

> The term "topo" in `lstopo` stands for "topology" (referring to computer system topology).

## Installation
Many Linux distributions come with `hwloc` preinstalled. If your system lacks it (e.g., Ubuntu), install it with:

```bash
sudo apt install hwloc
```

>`lstopo` is responsible for visually displaying the topology detected by `hwloc`.

Alternatively, install it manually from [Portable Hardware Locality (hwloc)](https://www.open-mpi.org/projects/hwloc/). Download from the "Sub-Projects" section, as highlighted in the red box below:

## Print to Command Line
To print a nicely formatted system topology directly in the terminal, use this simple command:

```bash
lstopo --of ascii -p
```

### Parameter Explanations:
- `--of ascii`: Specifies ASCII output (uses ASCII art—characters arranged to form a diagram). For example, here’s an ASCII art door:

<div style="text-align: center;">
  <img alt="Example of ASCII art door" src="/assets/images/6a833f8f4c29431799c81e14a4ef513d.png" style="box-shadow: 0px 0px 0px 0px; width: 50%;">
</div>

- `-p`: Prints physical IDs (labeled as `P#`; use `-l` for logical IDs labeled `L#`).

## Generate Image/File Formats
`lstopo` supports generating formats like PNG, JPG, SVG, PDF, and XML. Below is an example using SVG:

<div style="text-align: center;">
  <img alt="Sample SVG topology diagram generated by lstopo" src="/assets/images/260d94ff3a554377bf24dd05a5f600ce.png" style="box-shadow: 0px 0px 0px 0px; width: 70%;">
</div>

### Command to Generate SVG:
```bash
env LANG=zh_CN.UTF-8 lstopo --output-format svg > 1.svg
```

>`--output-format` is the full name of the shorthand `--of`.

### Key Note for Chinese Display:
The `env LANG=zh_CN.UTF-8` prefix ensures Chinese characters render correctly (without it, Chinese text may appear as square boxes `□`):

<div style="text-align: center;">
  <img alt="Broken Chinese text (square boxes) without proper LANG setting" src="/assets/images/2f3c100fce8644cbbef1b80b398e3c83.png" style="box-shadow: 0px 0px 0px 0px; width: 40%;">
</div>

### Simplified Command:
You can also use this shorter command to generate files (automatically detects format from the extension):
```bash
env LANG=zh_CN.UTF-8 lstopo 1.svg
```

### Overwrite Existing Files:
Add the `-f` flag to force overwrite existing files:
```bash
env LANG=zh_CN.UTF-8 lstopo 1.svg -f
```

### Other Formats:
Replace the file extension to generate other formats:
- XML: `env LANG=zh_CN.UTF-8 lstopo 1.xml`
- PNG: `env LANG=zh_CN.UTF-8 lstopo 1.png -f`

For all supported formats, see the "OUTPUT FORMATS" section in [lstopo(1) - Linux man page](https://linux.die.net/man/1/lstopo).

> Why did I show the longer `--output-format` command first? Many documents use it—likely for historical reasons. I prefer documenting multiple working methods; you never know when a specific scenario might require one over the other.

## Important Note: PNG/JPG Quality Issues
PNG and JPG are common formats (e.g., for blog posts), but they tend to be blurry (not due to compression). Smaller images may look acceptable, but larger ones suffer from poor clarity:

<div style="text-align: center;">
  <img alt="Blurry PNG topology diagram" src="/assets/images/1eaced78ec9044538b77254d6901d2e1.png" style="box-shadow: 0px 0px 0px 0px; width: 60%;">
</div>

### Solution: Use PDF as an Intermediate Format
To get clear images:
1. Generate a PDF first.
2. Convert the PDF to PNG/JPG.

<div style="text-align: center;">
  <img alt="PDF to image conversion workflow" src="/assets/images/0183a38921c54a9bb4001f951c04adfb.png" style="box-shadow: 0px 0px 0px 0px; width: 30%;">
</div>

The resulting image will be sharp:

<div style="text-align: center;">
  <img alt="Clear image converted from PDF" src="/assets/images/251cb8232e5b4c1682aa85a1db2b3b1e.jpg" style="box-shadow: 0px 0px 0px 0px; width: 70%;">

### Why Not SVG as an Intermediate Format?
On macOS, converting SVG to images often results in empty files for unknown reasons:

<div style="text-align: center;">
  <img alt="Empty file after SVG to image conversion on macOS" src="/assets/images/dd6a6e4cbf7b405f8f561224a4252ff9.png" style="box-shadow: 0px 0px 0px 0px; width: 40%;">

Third-party tools can fix this, but I prefer using built-in utilities when possible.
