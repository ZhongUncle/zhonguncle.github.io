Swift is primarily designed for Apple platforms, but it also supports development on Linux and Windows—especially for command-line applications, it works quite well.

However, since the core development team is relatively small, their focus remains on Apple’s Xcode and GUI development. When working outside of Xcode and GUI environments, various odd issues may pop up. I plan to publish several blog posts covering these issues in the coming days.

## Root Cause
This issue likely arose because I corrupted some system files while uninstalling Xcode and building LLVM/Clang from source. Reinstalling Xcode or installing Clang/Swift via Homebrew did **not** resolve the problem in this case.

## Solution
It is recommended to install Xcode (if not already installed), then reset the toolchain with `sudo xcode-select --reset`—this will fix the issue:
